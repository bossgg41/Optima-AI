## 2024-06-14 - Masking Passwords in Compose UIs
**Vulnerability:** A local `OutlinedTextField` used for an administrative role upgrade was inadvertently configured to show user input in plain text, making it vulnerable to over-the-shoulder snooping and device predictive text caches caching sensitive authorization hashes.
**Learning:** Even internal mock or pseudo-authentication forms must adhere to visual transformation standards. Developers often forget to apply transformations when building quick internal dialogs compared to building proper "Login" screens. Additionally, security theater should be avoided: hiding "hardcoded" secrets or hashes in `BuildConfig` using tools like Secrets Gradle Plugin still leaves those values accessible if someone reverse-engineers the APK.
**Prevention:** Apply `visualTransformation = PasswordVisualTransformation()` and `keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Password)` to all sensitive input fields (e.g., using Jetpack Compose `TextField` or `OutlinedTextField`) to prevent plaintext exposure and predictive text caching.
